# Security Policy

This is a public repository. Do not include secrets, credentials, tokens, passwords, private keys, or sensitive personal data in issues, pull requests, commits, documentation, or examples.

For repository development and AI Agent rules, see [AGENTS.md](AGENTS.md). It is the single source of truth for secret-handling and Agent workflow rules.

## Reporting A Secret Exposure

If you believe a secret was exposed:

- Do not copy the secret into an issue, pull request, chat message, or log.
- Report the affected file path or general location without revealing the value.
- Rotate or revoke the exposed credential immediately.
- Remove the secret from the repository history before making the repository public or continuing development.
