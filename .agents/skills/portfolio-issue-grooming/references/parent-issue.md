# Parent Issue Format

Use this format for the draft and the resulting GitHub parent Issue.

```markdown
## 目的

## 要求の要約

## 受入条件

- [ ]

## 対象外

-

## 関連する業務フロー・画面

## 人間が判断した事項

## 開発管理

- Project Status：未着手
- 設計Sub-issue：
- テストSub-issue：
- セッションログSub-issue：
- 関連PR：

## セキュリティ確認

実在患者の情報、個人情報、認証情報、APIキー、Tokenを記載しない。
```

## Sub-issue titles

- `Design: <parent issue title>`
- `Test: <parent issue title>`
- `Session Log: <parent issue title>`
