# Project Purpose

このリポジトリは、転職活動用の公開ポートフォリオです。

評価対象はWebアプリそのものだけではなく、次の開発能力を含みます。

- 要件整理と設計判断
- Issue / Sub-Issueを用いた開発管理
- 実装、テスト、コードレビュー
- 人間の判断とフィードバックの反映
- AI Agentの活用と作業履歴
- CI/CD、ドキュメント、技術選定理由

GitHubを第三者が閲覧したときに、何を作っているか、なぜその構成なのか、どのようなプロセスで開発しているか、AIと人間が何を担当したかを理解できる状態を目指します。

現時点では、システム概要を確定し、アプリ本体の実装より先にAgent運用・ドキュメント・セキュリティの基盤を整備しています。システムの対象範囲は[プロジェクト要件](product-requirements.md)を参照してください。
