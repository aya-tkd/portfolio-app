## API連携（画面から利用する場合）

画面からAPIを利用する場合に記載する。ここは画面利用者・実装者向けの連携概要であり、API全体の仕様書や契約の正本を複製する場所ではない。独立したAPI仕様がある場合はそちらを参照し、画面固有の利用方法だけを書く。

| HTTP method / URL | Request（query / path / body、主要な型・必須条件） | Response（成功時の主要データ） | 主なエラーと画面の扱い |
|---|---|---|---|

- 操作名は本文だけで対応が分からない場合に限り補足する。「呼出元→受け先」はAPI連携の必須項目ではない。
- 画面判断に必要な主要項目を記載し、全フィールドの転記や内部実装・業務ルールの重複を避ける。複雑なrequest bodyだけ最小JSON例を添える。
- 書込APIの共通CSRF取得・送信は[アーキテクチャ概要](../../architecture/overview.md)を参照し、各画面で同じ説明を繰り返さない。
- APIを利用しない画面では、この節を削除する。
