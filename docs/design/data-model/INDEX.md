## 作成規約

- ファイル名は実装上のテーブル名と一致させる。
- テーブル設計Docは、[テーブル設計テンプレート](templates/table.md)を複製して作成する。
- migrationが実装後の物理スキーマの正本である。
- テーブル設計Docには、業務上の意味、関連する画面・操作、制約の意図を記録する。
