# mst_reservation_slots

診察・設備の予約取得に使う、繰り返し時間枠のマスタ。患者別の予約実績や日付別の空き数は持たず、後続の予約取得が対象日と開始時刻へ展開して利用する。

| カラム | 意味・制約 |
|---|---|
| id | SQLite自動採番の内部ID。更新不可 |
| name | 必須、100文字以内の枠名。MRIのような設備も枠名で表す |
| slot_group | `consultation` / `equipment`。分類であり、設備そのものの識別子ではない |
| weekdays_mask | 月曜=1〜日曜=7をビット集合で保持。1〜127、少なくとも1曜日 |
| valid_from / valid_to | 必須の有効開始/終了日。開始日以下/以上の範囲 |
| start_minute / end_minute | Tokyo日内分。開始0〜1439、終了1〜1440、開始<終了。終了24:00を許容、日跨ぎなし |
| interval_minutes | 必須の正整数分。時間帯を等分できる値 |
| capacity | 分割後の各開始時刻に共有する必須の正整数定員 |
| default_department_id | 任意の`mst_departments` FK。有効な初期診療科のみ有効枠へ保存できる |
| default_doctor_user_id | 任意の`mst_users` FK。有効な医師職種で、初期科があればその科または所属未設定のユーザーのみ |
| display_order | 必須、0以上の整数。検索表示の優先順 |
| active | 必須。有効枠だけを後続の新規予約対象とする |
| lock_version | Railsの楽観ロック用。古い編集画面による上書きを409で防ぐ |
| created_at / updated_at | Rails管理時刻 |

`trn_appointments.reservation_slot_id`はNULL許容の外部キーでこのテーブルを参照する。既存の枠なし予約・文字列設備名はNULLのまま残す。予約に1件でも参照されると、グループ・曜日・期間・時刻・間隔・定員は更新不可とし、名称・初期値・状態だけを更新できる。これは取得済み予約の日時や定員判断をマスタ編集で壊さないためである。

同じMRIを別枠で共有しない運用を前提とするため、別レコード間の資源重複制約は置かない。将来、設備を複数枠で共有する必要が生じた場合は、枠グループとは別に設備IDと重複制御を設計する。
