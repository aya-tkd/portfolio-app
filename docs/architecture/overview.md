# Architecture Overview

## 現在の状態

アプリ本体は未実装です。現時点で確定しているのは、公開ポートフォリオとして開発プロセスと設計判断を追跡可能にする方針です。

## 構成方針

- ユーザーが理解できる最も単純な構成から開始する。
- 要件に必要な技術だけを採用する。
- 不要なマイクロサービス、DDD、CQRS、Repository Patternなどを先行導入しない。
- 構成を高度化する場合は、実際の問題、代替案、学習コスト、導入効果をADRに記録する。

Rails、Node.js、Vue、CSSフレームワークの採否や役割分担は、アプリ要件の整理後に決定します。決定した内容は本書とADRを更新します。
